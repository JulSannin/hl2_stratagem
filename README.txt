HD2 Stratagem LAN 0.21.0

Требования: Windows 10/11, Python 3.12 или новее.

Запуск:
1. Распакуй архив в отдельную папку.
2. Запусти run_server.bat.
3. Открой адрес из консоли в Edge / Xbox Game Bar. PIN не нужен.
4. Нажми виртуальную клавишу Numpad, чтобы назначить стратагему.

Главный экран — только Numpad и шестерёнка. Выбор стратагем открывается поверх Numpad.
В окне выбора категории расположены адаптивной сеткой без горизонтального ползунка. Поиск находится только внутри окна выбора и фильтрует текущую категорию. Сетка содержит оригинальные цветные игровые SVG-иконки без названий и кодов. Уже назначенные стратагемы показаны в верхней полосе иконок и отмечены в каталоге. Нажатие на назначенную клавишу открывает категорию её текущей стратагемы. При наведении на иконку через 0,5 секунды над плиткой появляется название и стрелочная комбинация; подсказка не перекрывает иконку.

Шестерёнка открывает отдельное адаптивное окно настроек. На узких и низких окнах содержимое диалога прокручивается внутри, а не растягивает страницу.

Настройки сохраняются в %APPDATA%\HD2StratagemLAN\config.json. Игровые SVG кешируются в %APPDATA%\HD2StratagemLAN\icons.

Безопасность: PIN и авторизация отключены. Любое устройство в доверенной локальной сети, знающее адрес сервера, сможет менять назначения и запускать макросы. Не пробрасывай порт 8765 в интернет.

Версия 0.19.0 — синхронизация нескольких окон:
- Edge/Game Bar и Chrome получают одинаковые назначения и настройки через общий WebSocket.
- При подключении вкладка сразу получает актуальный снимок конфигурации от сервера.
- Изменения отправляются всем открытым клиентам без перезагрузки страницы.
- Физические нажатия Numpad, как и раньше, анимируются во всех подключённых окнах.
- Версионность конфигурации защищает от перезаписи новых данных старой вкладкой. Если два окна меняют разные клавиши одновременно, клиент автоматически объединяет независимые изменения и повторяет сохранение.
- Состояние WebSocket автоматически восстанавливается после обрыва связи.


Синхронизация 0.19.0: все открытые браузерные клиенты используют единое состояние сервера. Изменения назначений и настроек мгновенно рассылаются по WebSocket. Одновременные независимые изменения объединяются с помощью revision, чтобы одна вкладка не перезаписывала другую.



Версия 0.19.0 — техническое ревью и надёжность:
- Исправлен повторный keydown при удержании назначенной клавиши: авто-повторы Windows больше не проходят сквозь hook и не печатаются в игре.
- Макрос получает неизменяемый снимок настроек на момент запуска; изменения из другой вкладки применяются только к следующим комбинациям.
- Сокращена работа в low-level hook: проверка фокуса выполняется один раз, передача команды не повторяет дорогую проверку процесса.
- WebSocket-рассылка сериализована, отправка нескольким клиентам выполняется конкурентно, ошибки/отключения удаляют нерабочие соединения.
- WebSocket проверяет Origin, чтобы посторонняя веб-страница не могла незаметно подключиться к локальному сокету.
- Если запись config.json не удалась, сервер откатывает состояние в памяти и revision, не показывая ложное сохранение.
- Добавлены регрессионные тесты для удержания клавиш, фокуса игры, снимка настроек, Origin и ошибки диска.


Версия 0.20.0 — Optimization & Reliability Review:
- WebSocket handshake теперь отправляет canonical `ready` под тем же lock, что и broadcast: клиент не может получить update до initial snapshot.
- Медленные/отключённые WebSocket-клиенты исключаются из рассылки по таймауту, не блокируя остальные окна.
- Windows low-level hook стал идемпотентным, корректно останавливается при shutdown и игнорирует SendInput-инжектированные события.
- Повторный keydown удерживаемой клавиши продолжает поглощаться; устаревшее состояние после потерянного key_up автоматически очищается при следующем нажатии.
- Кэш SVG защищён per-icon lock и атомарной записью: две вкладки не читают частично записанный файл.
- config.json записывается через flush/fsync + atomic replace; повреждённый JSON сначала сохраняется в резервную копию `.corrupt-*`.
- Добавлена защита локального Host/Origin от DNS rebinding и межсайтовых записывающих запросов; доступ по localhost, private IP и имени этого ПК остаётся.
- Клиент при 409 предпочитает более свежую ревизию из WebSocket, выполняет до четырёх bounded merge-retries и не откатывает состояние поверх более новой синхронизированной конфигурации.
- Минимальная версия Python повышена до 3.12: Python 3.10 завершил поддержку 2026-10-01.

Известный техдолг:
- Вендорный browser runtime остаётся React 16.0.0 / ReactDOM 16.0.1 UMD. Обновление до актуальной React 19 требует отдельной миграции от глобальных UMD script tags и полноценного production build; бинарники React 19 в офлайн-среде не были доступны, поэтому рискованный полусдвиг версий не делался.
- Реальная работа WH_KEYBOARD_LL / SendInput требует финального прогона на Windows с запущенной Helldivers 2.


Оптимизация запуска 0.20.0:
- При запуске проверяются диапазоны версий FastAPI, Uvicorn и Pydantic и наличие компонентов uvicorn[standard]. Если окружение уже соответствует требованиям, pip не запускается повторно.


Версия 0.21.0: всплывающие окна выбора и настроек закреплены у верхнего края окна; подсказка над иконкой стратагемы появляется через 0,5 секунды и содержит название и стрелочную комбинацию. Подсказка не обрезается прокручиваемой сеткой.
