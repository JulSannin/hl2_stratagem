HD2 STRATAGEM LAN 0.20.0

Требуется Windows 10/11 и Python 3.12 или новее.
При первом запуске создаётся .venv и устанавливаются зависимости. При следующих запусках pip пропускается, если установленное окружение подходит.

1. Запусти run_server.bat.
2. Открой адрес, показанный в консоли, в Edge / Xbox Game Bar. PIN не нужен.
3. Нажми виртуальную клавишу Numpad, чтобы открыть выбор стратагем.
4. Выбери тип стратагемы и нажми нужную цветную игровую иконку.
5. При наведении на назначенную клавишу через 0,5 секунды появится название стратагемы и её код стрелками.
6. Нажми шестерёнку для настроек управления и скорости ввода.

Все 111 стрелочных кодов проверены по актуальной опубликованной базе Divers Hub на 30.10.2026; см. DATA_AUDIT_2026-10-30.md. Это общественная база, не прямой dump установленных игровых файлов.

7. Можно одновременно держать интерфейс открытым в Edge/Game Bar и Chrome: назначения и настройки синхронизируются между всеми вкладками автоматически. Физические нажатия Numpad также отображаются во всех открытых окнах.
8. После установки новой версии обнови обе открытые страницы. Если браузер показывает старую версию, используй Ctrl+F5.

Всплывающие окна открываются от верхнего края окна Game Bar. При наведении на иконку в каталоге через полсекунды над ней показываются название и код стрелок.
